# 寶可夢訓練家計劃 · 像素夥伴製造機

布拉克星球老師系統的像素角色與動畫編輯器。第二階段加入最多 4 格角色動畫，介面改為大型復古掌機：厚外殼、LCD 色調、像素草地、十字鍵與 A / B 按鈕。

正式網址：https://blockplanetcamp.com/teacher-tools/pokemon-trainer/

## 開始製作動畫

1. 畫好第 1 格角色，按「複製此格」。
2. 在第 2 格修改眼睛、手腳或尾巴；「前一格淡影」可以協助對齊。
3. 按 A 或「播放動畫」，用滑桿調整每秒 1～12 格。
4. 下載「動畫作品檔」，保存全部畫格與速度，之後可以再開啟編輯。

- 1 格保留作為靜態作品；加入第 2 格後可播放動畫，上限 4 格。
- 畫格可以新增空白格、複製、前後排序、刪除。刪除、清空、畫布裁切均可復原。
- 十字鍵切換畫格；A 播放／暫停；B 復原；SELECT 開啟收藏；START 新增夥伴。
- 畫布支援 16、32、64 格，滑鼠、觸控筆、手指使用 Pointer Events。
- 保留畫筆、橡皮擦、填色、吸色、左右對稱、筆尖、自訂色、透明色與復原重做。
- 畫布聚焦時，方向鍵移動游標、空白鍵上色。B / E / F / I 切換工具；Ctrl / ⌘ Z 復原。

## 匯出

| 格式 | 內容 |
| --- | --- |
| 動畫作品檔 `.tpsprite.json` | 全部畫格、名稱、尺寸與播放速度；可再次編輯 |
| 此格 PNG | 目前編輯的畫格，透明背景，原尺寸或 8 倍放大 |
| 逐格圖集 PNG | 所有畫格依順序橫向排列；這是靜態圖片，不是 GIF |

播放只更新預覽，不會更改正在編輯的畫格、繪圖內容或作品時間；切換作品、繪圖、開啟對話框、離開分頁時會停止播放。動畫由使用者啟動，不會自動播放。

## 保存與舊作品相容

作品只保存在目前瀏覽器的 localStorage，最多 40 件，容量仍受瀏覽器配額限制。尚無帳號或雲端同步。清除網站資料、換瀏覽器或裝置前，請下載作品檔備份。保存失敗會顯示警告，下載仍可使用。

- 儲存 key 維持 `teampoke.trainer.v1`，內容格式升為 version 2。
- 舊版收藏和 v1 作品檔會以原圖轉成單格作品，保留名稱、收藏 ID 與日期。
- 第一次覆寫 v1 收藏前，先將原始內容保留在 `teampoke.trainer.v1.v1-backup`；備份失敗不會覆寫原收藏。
- 損壞的收藏先保留在 `.recovery` key，再保存新作品；無法保留時拒絕覆寫。
- v2 作品使用 `frames`（1～4 個像素陣列）與 `fps`（整數 1～12）；`activeFrame` 只保存於瀏覽器收藏。舊版編輯器不能讀取 v2 動畫檔。
- 繪圖使用目前畫格的 `pixels` 存取器，序列化只保存 `frames`，不重複存像素。

## 部署與開發

純靜態 HTML / CSS / ES modules，沒有第三方執行時依賴。目錄 `teacher-tools/pokemon-trainer/`；老師選單在 `camp2027/camp-data.js`。使用既有 GitHub Pages main 分支部署，不需修改 Apps Script。

Node.js 22+：

```sh
npm ci
node --test tests/*.test.mjs
node --check app.js
```

### 播放相容性修正

原生計時器必須以全域物件呼叫，不能存成播放器方法後直接呼叫。播放與清除計時器都改由全域呼叫包裝；新增會檢查接收者的回歸測試，舊版會重現 Illegal invocation，修正版通過。DOM 測試也驗證不同畫格的實際繪圖資料有切換。只有一格時按播放會提示新增第二格，所有畫格相同時提示修改圖案。

參考：[MDN 計時器的 this 說明](https://developer.mozilla.org/zh-TW/docs/Web/API/Window/setInterval#「this」問題)。仍未取得實機瀏覽器驗證。
