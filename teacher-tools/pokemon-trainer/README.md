# 寶可夢訓練家計劃 · 自繪夥伴

布拉克星球老師系統的像素角色編輯器。第一階段先做角色自繪，之後逐步加入招式與遊戲機整合。

## 使用

- 畫布：16、32、64 格，滑鼠、觸控筆或手指皆使用 Pointer Events。
- 工具：畫筆、橡皮擦、填色、吸色、左右對稱、筆尖大小、自訂顏色、透明色。
- 復原與重做以整次筆畫為單位；縮小畫布前提醒裁切，可復原。
- 畫布可用方向鍵移動游標、空白鍵上色。B / E / F / I 切換工具；Ctrl / ⌘ Z 復原。
- 我的作品：新增、複製、切換、刪除；首次提供原創「芽芽」練習圖案。
- PNG 匯出：透明背景，原始尺寸或 8 倍整數放大。
- 作品檔：`.tpsprite.json`，可重新開啟繼續編輯。

## 保存範圍

作品只存於目前瀏覽器的 localStorage，最多 40 件。尚無帳號或雲端同步；清除網站資料、換瀏覽器或裝置會影響收藏，請下載作品檔備份。每個作品保留建立與更新時間，不收集孩子個資。儲存失敗會顯示警告，匯出仍可使用。損壞的既有收藏在新作品首次保存前，會先複製到 recovery key；若無法保留，拒絕覆寫。

## 部署與原始碼

純靜態 HTML / CSS / ES modules，沒有第三方執行時依賴。正式整合目錄 `teacher-tools/pokemon-trainer/`，入口在 `camp2027/camp-data.js` 的 `teacherLinks`。透過既有 GitHub Pages 網站部署，不需修改 Apps Script。

參考 MakeCode Arcade 的精靈繪圖操作概念：[官方教學](https://arcade.makecode.com/courses/csintro1/intro/sprites)。本工具的 UI、程式與練習角色為本專案製作，並未複製 MakeCode 原始碼或寶可夢官方圖像。

## 驗證

Node.js 22+：`node --test tests/*.test.mjs`，`node --check app.js`。

13 項測試通過（12 項模型測試、1 項 DOM 整合測試）。DOM 測試使用 happy-dom 與畫布替身，驗證控制按鈕、筆畫、收藏及下載串接；不代表真實畫面或觸控已驗證。開發依賴以 `npm ci` 安裝，不會送到網頁執行。

模型測試涵蓋筆畫連續性、對稱、填色邊界、透明色、復原重做、裁切還原、作品匯出匯入、收藏還原與錯誤資料。

這次環境沒有可用的瀏覽器控制連線，因此尚未完成實際桌機／手機瀏覽器點擊與觸控手感驗證。
