    GAME SYSTEM

    安裝／更新遊戲系統

    由網站準備好遊戲，電腦不需要安裝開發套件。只有新增功能或第一次使用時才需要更新系統。

    StopWatch C152 專用 · USB 寫入測試版，尚待實機驗證

    第一次安裝會清除設備原有系統與資料。若已有本遊戲的進度，請改選「更新現有遊戲」。寫入前會先備份整台設備。

    1. 接上 USB 資料線。若無法連接，依下方說明進入下載模式。
    2. 按「連接並備份」，在瀏覽器選擇 StopWatch。
    3. 下載 16 MB 還原備份，保存後開始寫入。

    系統會先辨識晶片、容量，再備份與校驗；這一步尚不寫入韌體。

    找不到設備、黑畫面或更新中斷？

    請關閉 Arduino 序列監控或其他占用 USB 的程式。用可傳資料的 USB 線連接 StopWatch，長按電源／重置鍵約 2 秒，直到綠燈亮起後放開，再按「連接並備份」，選擇「USB JTAG/serial debug unit」（Mac 名稱通常含 cu.usbmodem）。若更新中斷，保留下載的備份，重新進入下載模式再試；不要改選第一次安裝來處理既有進度。

    完成「讀回校驗」表示檔案已寫入；還需要重新開機、回到創作頁按「連接遊戲機」，才能確認遊戲正常回應。
