# 全國廢材機器人大賽改版與啟用

2026-10-02。此版為已核准發布的全國賽事改版。正式 Apps Script 已於當日部署第 41 版，沿用原部署網址，並確認 national v2 的正式只讀回應正確。前台發布以本版本的 GitHub Pages 部署結果為準。賽務登入另需由主辦方設定專用密碼。

## 目前設計與資料範圍

- 全國單一賽事入口，不再選擇或切換教室；目前依單一組別／單一項目、一隊一位選手製作。
- 保留已確認的「本輪對戰／完整晉級圖」、一分鐘不停錶、裁判判勝及每場最多一次重賽。
- 重整入口、賽務總覽、名單、賽果紀錄與觀眾資訊順序。新增報到註記、名單搜尋、匯入前逐筆核對、抽籤規則確認、完整備份及 CSV 賽果。
- 報到註記供現場核對；抽籤包含名單中的全部隊伍，未報到隊伍不會自動排除。抽籤確認會明示隊數與報到數。
- 全國資料使用獨立的 `national` 資料列；舊 `dongqiao`、`north` 資料及舊 API 相容性保留，不合併、不刪除。
- 演練模式僅用本機 `bp-junkbot-demo-national`，不寫入正式資料。

## 國賽操作保護

- 正式密碼由後端指令碼屬性設定，不放在前端。工作人員姓名／代號是自行輸入的登錄資訊，不是經驗證的個人身分。
- 全國前端只接受相符的 `scope: national` 及 `protocolVersion: 2`。未部署新版後端時停止操作，不會退回使用教室資料。
- 整份資料儲存會比對 revision。遇到其他裝置更新時，保留本機修改並要求核對，不能直接覆蓋；可下載備份再載入最新資料。
- 賽場操作由後端逐項驗證。重複開始不會重設截止時間，不能提前結束倒數，重賽不得超過一次，已判定結果不可改寫。
- 每場判定保存原因、時間、登錄人員與操作紀錄。現場狀況判定需填補充說明。封存完整保留每場紀錄。
- 觀眾頁顯示同步時間及失敗狀態；伺服器時間用於校準倒數。本機瀏覽器快取不是正式資料來源。

## 啟用順序

1. 先確認新版版面，並由主辦單位核定本次競賽規程。既有算法為實際隊數逐輪減半，單數輪次預排輪空：例如 6→3→2、10→5→3→2。只有經過四強的路線安排季軍戰；經過三強的路線以該輪實戰落敗隊列季軍。抽籤前會完整列出，不擅自更改原賽制。
2. 將專案 `camp2026/apps-script.gs` 完整內容貼入既有 Apps Script 專案「優惠券系統」的「程式碼.gs」，儲存。保留其他檔案。
3. Apps Script「專案設定 → 指令碼屬性」新增 `JUNKBOT_NATIONAL_PASSWORD`，設定至少 12 字元的專用密碼；舊公開前端密碼不適用全國賽事。
4. 「部署 → 管理部署 → 編輯 → 新版本 → 部署」。優先更新既有部署以保留 URL；若 URL 改變，先同步網站 API_URL。新版後端保留舊教室 API，可先部署後端再發布新前端。
5. 確認全國讀取回應包含 `scope: national`、`protocolVersion: 2`、`state.revision`；再以正式賽務密碼登入，確認讀取正常與全國資料獨立。
6. 版面確認後發布前端。正式競賽前，以主控裝置、第二控制裝置與觀眾投影共同完成一次現場連線演練，包括開場、到時、判定、衝突處理及匯出。只有實際現場驗收完成後，才可稱為可正式競賽。
